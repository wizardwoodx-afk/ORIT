Reading face — pick one, it becomes --font-serif

A serif is a delivery decision, not a decoration. At 17px with an optical size axis, the reading face carries a long answer without the interface having to shout. Chrome stays in the sans; anything with a number in it stays in the mono.

Untrusted text arrives in the same face, because the reader has to see that it is text and not a system statement. The label chip above it is what marks provenance: web, untrusted.

03

State vocabulary

Fifteen states, each with a glyph on the 16px grid, a label, and a reason line. A spinner is not one of them. Only running rotates; only needs-approval breathes.
